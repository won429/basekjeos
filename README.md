# Nook

YouTube Music의 현재 재생 세션을 노치에서 보여주고 제어하는 작은 메뉴 막대 앱입니다.

## 기능

- **2.1**: YouTube Music 브라우저 접근성 탐색 캐시·상태 변화 감지, 유휴 재탐색 백오프, 표지와 높이를 맞춘 가사 영역, 현재 가사 확대, 앨범 표지 포커스 강조 제거. [변경 내역](CHANGES-2.1.md).

- **2.0**: 몰입화면 전환 시 노치·아일랜드 팽창 모션, Safari·Chrome 계열 YouTube Music 페이지 연동, 다른 플레이어의 상태·명령 격리. [변경 내역](CHANGES-2.0.md).

- **1.2.3**: 아이콘 여백 수정, 메뉴 막대 기본 접힘 안정화, 펼친 영역 외부 클릭으로 접기, 몰입 화면 위 노치·아일랜드 유지. [변경 내역](CHANGES-1.2.3.md).

- **1.2.2**: Nook으로 이름 변경, 제공된 아이콘 적용, 날짜 시작점에 가사 정렬, 가사 27pt 고정, 스크롤바 재표시 수정. [변경 내역](CHANGES-1.2.2.md).

- **1.2.1**: 몰입 화면 표지·재생바의 기본 360pt 폭 복원, 화면 크기에 따른 여백 배치, 새 앱 아이콘 적용. [변경 내역](CHANGES-1.2.1.md).

- **1.2**: 표지 선택 테두리 제거, 가사 스크롤바 숨김 보완, 화면 크기에 맞춘 몰입 화면, 재생목록 조회 복구, Dock·강제 종료 목록 표시. [변경 내역](CHANGES-1.2.md).

- **1.1.2**: 실행 시 메뉴 막대를 처음부터 접힌 상태로 생성합니다. 초기화 지연과 첫 접기의 타이머 의존성을 제거했습니다. [변경 내역](CHANGES-1.1.2.md).

- **1.1.1**: 앱 시작 시 메뉴 막대 아이콘을 자동으로 접습니다. 초기 배치가 준비되지 않았으면 기존 감시 주기에서 재시도하고, 수동 펼치기 및 10초 후 자동 복귀는 유지합니다. [변경 내역](CHANGES-1.1.1.md).

- **1.1**: 기존 화면·모션·기능을 유지하면서 보조 프로세스 교착 방지, 메인 스레드의 오디오 장치·AirPods 조회 분리, 전원 변경 알림 기반 배터리 감시, 앨범 이미지 중복 처리 제거, FFT 작업 메모리 재사용을 적용했습니다. 자세한 변경과 검증은 [CHANGES-1.1.md](CHANGES-1.1.md)를 참고하세요.

- **1.0.6**: 몰입 파형 배경은 반주의 에너지에 맞춰 색 흐름이 상하좌우로 이동합니다. 노치 알림은 기본 노치 폭 전체를 센서 영역으로 확보한 뒤 양옆으로 확장합니다. 다이나믹 아일랜드 볼륨·밝기 글자 크기를 배터리와 통일하고, 긴 AirPods 이름에 맞춰 연결 화면을 넓힙니다. 몰입 재생목록은 현재 YouTube Music 페이지의 실제 다음 트랙을 손쉬운 사용 연결로 읽습니다. 목록을 열거나 곡이 바뀔 때 조회하며 다시 가져오기를 제공합니다. 권한이나 페이지 데이터가 없으면 안내를 표시합니다.

- **1.0.5**: 몰입 파형 배경은 작은 음악 파형 설정과 독립적으로 오디오 분석을 켜고, 저음·중음·고음에 따라 각 물결의 높이와 위치가 반응합니다. 화면을 닫거나 기본 배경으로 바꾸면 배경용 분석을 해제하며 기존 실제 파형 사용은 유지합니다. macOS 26의 글래스 버튼은 검은 틴트 없는 Clear 스타일을 사용합니다.

- **1.0.4**: 메뉴의 ‘배경 그래픽 모드 설정’에서 기본·파형 모드를 선택하고 저장합니다. 기본 배경은 원형 대신 넓게 혼합되는 색 흐름이며, 파형 배경은 세 겹의 부드러운 물결입니다. 실제 파형 모드에서 이미 수집 중인 오디오 데이터가 있으면 물결 강도에도 반영하며 별도 녹음을 시작하지 않습니다. 일시 정지·동작 줄이기·저전력 모드에서는 배경 움직임을 멈춥니다. 다이나믹 아일랜드 표지·파형을 캡슐의 실제 중앙에 맞추고 어두운 음악 파형 색은 밝은 회색으로 표시합니다.

- **1.0.3**: 가사 조회에 곡명·아티스트 표기 정리와 검색 보완, 일시 오류 자동 재시도를 추가했습니다. 빈 결과는 캐시하지 않으며 다시 가져오기는 새로 조회합니다. 해당 버튼에도 Liquid Glass를 적용했습니다. 한국어 설정에서는 같은 곡의 한글 가사를 우선하고 언어 변경을 즉시 반영합니다. 한글 가사가 없으면 제공된 원문을 표시하며 자동 번역은 하지 않습니다.

- **1.0.2**: 몰입 화면의 재생바를 펼친 노치·다이나믹 아일랜드와 동일한 컴포넌트로 통일했습니다. 재생 버튼 아래에 시스템 볼륨 바·음소거/복원·출력 설정을 추가했습니다. 조절 불가능한 출력 기기에서는 볼륨 바를 비활성화하고 출력 설정을 제공합니다.
- 위쪽 화살표로 접으며, 화면 전체가 실제 상단 노치·아일랜드 위치에서 펼쳐지고 그 위치로 축소됩니다. 가사 재표시 시 로딩 깜박임을 없애고 구절의 등장·강조·자동 스크롤을 부드럽게 연결합니다.
- 배경은 앨범 색으로 만든 다섯 색상 레이어가 서로 다른 주기로 이동·회전·확대하며 혼합됩니다. 고정 크기 레이어를 합성하고, 일시 정지·동작 줄이기·저전력 모드에서는 멈춥니다.

- **1.0.1**: 컴팩트 표지·파형·음량·충전·배터리·AirPods의 중심선을 공통으로 보정하고, 알림 팽창 높이도 반영합니다. 펼친 AirPods의 문구와 배터리 링 중심도 맞췄습니다.
- 몰입 배경은 표지의 최대 세 가지 색을 Core Animation 레이어로 천천히 혼합합니다. 프레임마다 SwiftUI를 다시 그리지 않으며, 일시 정지·동작 줄이기·시스템 저전력 모드에서는 정지합니다. 닫으면 애니메이션을 해제합니다.
- 몰입 화면 상단은 날짜·시간을 분 단위로 갱신합니다. 재생 시간은 펼친 노치·다이나믹 아일랜드와 같은 13pt 시스템 Semibold 글꼴을 사용합니다.
- 우측 하단 가사·목록 버튼과 닫기 버튼에는 macOS 26의 네이티브 Liquid Glass를 적용하고, 이전 macOS에서는 반투명 소재로 표시합니다. 선택된 버튼을 다시 누르면 표지 중심 화면으로 전환됩니다. 목록 화면은 현재 곡과 YouTube Music 열기를 제공합니다. 현재 MediaRemote 브라우저 세션에 다음 곡 목록이 없어 앱 내부에 대기열을 복제하지 않습니다.

- **1.0 몰입형 음악 화면**: 펼친 플레이어에서 앨범 표지를 클릭하면 표지가 커지며 전체 화면으로 이어집니다. 왼쪽에는 큰 표지·곡 정보·재생 컨트롤, 오른쪽에는 현재 구절을 강조하고 자동 스크롤하는 가사가 표시됩니다. 표지 색으로 만든 움직이는 그라데이션 배경을 사용합니다. Esc 또는 왼쪽 위 닫기 버튼으로 돌아가고, 스페이스로 재생/일시 정지, 가사 클릭으로 해당 구절부터 재생할 수 있습니다.
- 가사는 몰입 화면을 열었을 때만 [LRCLIB](https://lrclib.net/docs)에 곡명·아티스트·앨범·재생 길이를 보내 조회합니다. 최대 40곡을 메모리 캐시하며 화면을 닫으면 요청과 구독을 해제합니다. 등록된 시간 가사가 없으면 일반 가사 또는 안내를 보여줍니다. 네트워크 오류는 수동으로 재시도할 수 있습니다. 별도 상시 타이머·오디오 분석·AI 호출을 추가하지 않고, macOS 동작 줄이기 설정을 반영합니다.

- 볼륨·충전 알림의 좌우 끝 여백을 음악 표지·파형과 통일합니다.
- 시스템 볼륨 표시 숨기기: 손쉬운 사용 권한을 허용하면 볼륨 키·음소거 키를 앱이 처리합니다. Shift+Option 미세 조절과 길게 누르기를 지원하며, 권한이 없거나 출력 기기를 조절할 수 없으면 시스템으로 넘깁니다. 메뉴에서 끄거나 권한 설정을 열 수 있습니다. 제어 센터를 직접 열어 조절하는 화면은 숨기지 않습니다.

- 음량 알림은 두 표시 형태 모두 음악보다 넓어지며, 중앙 카메라·센서 영역을 비우고 확장과 동시에 아이콘·문구·게이지가 나타납니다.
- 시스템 출력 음량 변경 시 스피커 아이콘·“음량”·게이지를 표시하고 마지막 조절 2초 후 복귀합니다. 음소거도 반영하며 오디오 녹음 권한을 사용하지 않습니다.
- 충전·배터리·AirPods·음량 알림이 새로 나타날 때 폭 8pt·높이 2pt 이내로 살짝 팽창했다가 복귀합니다. 연속 음량 조절에는 반응을 반복하지 않습니다.

- 노치를 중심으로 좌우로 펼쳐지는 낮은 가로형 플레이어
- 실제 MacBook처럼 상단 양쪽이 곡선으로 이어지는 노치 실루엣과 둥근 하단 모서리
- 화면 상단에 붙는 노치 모드와 분리된 캡슐형 다이나믹 아일랜드 모드
- 노치를 클릭하면 플레이어 확장, 다시 클릭하면 축소
- 노치·다이나믹 아일랜드의 펼침은 표지·곡 정보·진행 막대·버튼이 배경과 함께 커지고 이동하며, 전환 중 흐림이 선명해지는 방식입니다. 아래에 가려진 컨트롤을 뒤늦게 드러내지 않습니다.
- 노치 확장 화면은 420pt 너비와 넉넉한 안쪽 여백을 사용합니다. 앨범·곡 정보·파형과 탐색·재생 버튼의 간격을 확보하며, 배터리 부족 알림도 상하·좌우 여백을 넓혔습니다.
- 기기의 메뉴 막대 높이와 실제 카메라 하우징 폭에 맞춘 자동 크기 조절
- 재생/일시정지, 이전 곡, 다음 곡, 탐색
- 곡 정보를 읽는 연결을 유지해 0.2초 간격으로 변경을 확인하고 즉시 전달합니다. 연결 종료 시 기존 조회 방식으로 복구합니다. 표지의 앱 아이콘은 표시하지 않으며 표지 전환 애니메이션은 원래 속도를 유지합니다.
- Chrome, Safari 등 브라우저에서 재생 중인 YouTube Music만 감지
- Netflix, 일반 YouTube 영상 및 다른 앱의 미디어 세션은 표시·제어하지 않음
- 앨범 표지의 대표 색상과 시스템 오디오 레벨을 반영하는 실시간 파형
- 파형은 실제 표시 중인 표지를 sRGB로 변환해 추출한 최대 세 가지 색을 섞습니다. 채도·밝기를 강제로 높이지 않으며, 표지 전환 시 색도 표지가 바뀌는 순간에 맞춰 교체합니다. 표지가 없으면 중립 회색을 사용합니다.
- 재생 정보가 없을 때는 “재생 중이 아님”으로 표시하고 빈 표지에는 음표 아이콘을 표시하지 않습니다.
- 전원 연결/해제 시 배터리 잔량과 충전 상태 애니메이션 표시. 충전 알림의 잔량·배터리 색은 20% 이하 빨강, 21% 이상 초록입니다.
- 노치 모드의 배터리·충전·AirPods 알림은 좌우로 넓어지며, 실제 카메라 영역을 비워 두고 양옆에 정보를 표시합니다. 알림 종료 후 원래 너비로 복귀합니다.
- 전원 미연결 상태에서 잔량이 20% 이하이면 배터리 부족 알림이 자동으로 펼쳐집니다. 왼쪽에는 잔량·저전력 모드 안내, 오른쪽에는 빨간색 파동이 있는 배터리 버튼이 표시됩니다. 버튼을 누르면 macOS 관리자 인증을 거쳐 배터리 사용 시 저전력 모드를 켜거나 끕니다. 실제 시스템 활성화가 확인되면 버튼과 안내가 노란색으로 바뀝니다. 취소 시 기존 상태를 유지하고, 실패 시 설정 열기를 제공합니다. 알림은 7초 후 접히며, 버튼 조작 후에는 5초간 결과를 보여줍니다. 인증 중에는 자동으로 닫히지 않습니다. 잔량 알림 ‘끔’은 이 알림에도 적용됩니다.
- AirPods 착용·연결 시 iPhone 스타일의 연속 360도 제품 회전, 컴팩트 배터리 링, 확장 연결 정보 표시
- 메뉴 막대의 언어 설정에서 충전 및 AirPods 연결 알림을 한국어 또는 영어로 전환
- 배터리 잔량 알림: 음표 메뉴에서 1·5·10·20·30·40·50%단위 또는 끔 선택 (기본 10%)
  선택한 간격의 배수에 도달하거나 넘을 때 현재 잔량을 4초간 표시합니다.
  배터리 사용 중 잔량이 감소할 때만 알립니다. 충전 중 잔량 상승과 100% 도달 알림은 표시하지 않습니다.
  끔을 선택해도 충전기 연결·해제 알림은 유지됩니다. 설정은 재실행 후에도 저장됩니다.
- 노치는 정지·대기 상태에서도 기본 크기를 유지하고, 음악 재생 중에는 양옆으로 24pt씩 넓어집니다. 재생 정지 30초 후 자동 대기 모드로 전환되며, 다이나믹 아일랜드는 기존처럼 작아집니다.
- 노치의 재생 시작·정지 전환은 반동 없이 부드럽게 가감속하며, 대기 상태에서 표지·파형이 나타나는 정도를 폭 변화와 동기화합니다.
- 다이나믹 아일랜드도 대기↔음악 전환의 폭과 표지·파형 표시를 같은 프레임으로 동기화합니다. 별도 SwiftUI 상태 애니메이션이 캡슐의 위치·클리핑을 지연시키지 않도록 처리합니다.
- 배터리 부족 알림은 현재 크기에서 펼쳐지고, 종료할 때 충전·음악·대기의 실제 목적 크기로 바로 접힙니다. 알림 문구와 배터리 배치는 함께 축소되며 중간 캡슐로 줄었다 다시 늘어나는 단계를 거치지 않습니다.
- 다이나믹 아일랜드의 충전 알림은 문구 배치 폭을 유지하면서 부드럽게 넓어지고, 공간이 확보되면 내용이 나타납니다. 종료 시 충전 표시가 먼저 사라진 뒤 원래 상태로 돌아옵니다.
- 권한 없이 움직이는 기본 파형과 음악의 주파수 대역에 반응하는 실제 파형 모드
- 표지를 곡별로 캐시하고 MediaRemote·iTunes·YouTube를 병렬 조회해 빠르게 표시
- 모든 데스크톱과 전체 화면 앱 위에서 표시
- 메뉴 막대에서 플레이어 표시, YouTube Music 열기, 종료

## 빌드

macOS 13 이상과 Swift 6 Command Line Tools가 필요합니다.

```sh
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

생성되는 앱:

```text
dist/Notch Music.app
dist/Notch-Music-1.0.6.zip
```

Finder에서 앱을 열거나 다음 명령을 실행하세요.

```sh
open "dist/Notch Music.app"
```

0.9.45부터 독립 앱 식별자는 `com.notchmusic.app`입니다. 이전 개발 실행으로
`com.notchmusic.player`가 다른 앱의 메뉴 막대 허용 설정에 함께 등록된 Mac을 위해
식별자를 분리했습니다. 표시 형태·파형·언어·배터리 알림 설정은 한 번 자동 이전하며,
앨범 캐시는 기존 경로를 유지합니다. macOS의 녹음 권한은 다시 요청될 수 있습니다.
개발 중에도 실행 파일(`Contents/MacOS/NotchMusic`, `.build/release/NotchMusic`)을
직접 실행하지 말고, Finder 또는 위의 `open` 명령으로 앱 번들을 실행하세요.

YouTube Music을 Chrome 또는 Safari에서 재생하면 곡 정보가 자동으로 표시됩니다.
첫 실행 시 실제 파형을 위한 macOS의 `시스템 오디오 녹음` 권한을 물어봅니다. 이전 macOS에서는 `화면 및 시스템 오디오 녹음` 권한을 물을 수 있습니다. 앱은 화면 영상이나 오디오를 저장하지 않고 주파수 대역만 실시간으로 계산합니다.

메뉴 막대 아이콘의 `표시 형태`에서 노치 또는 다이나믹 아일랜드를 선택할 수 있습니다. 아이콘도 선택 즉시 화면 상단에 붙은 노치 또는 화면 안에 떠 있는 캡슐 아이콘로 바뀌며 재실행 후에도 유지됩니다. 밝은/어두운 메뉴 막대에 맞춰 아이콘 색이 자동으로 바뀝니다.

## 참고

이 앱은 macOS 15.4 이후의 MediaRemote 읽기 제한을 우회하기 위해 시스템 `osascript` 프로세스에서 현재 재생 정보를 읽습니다. 앱스토어 배포용이 아니며, 향후 macOS 업데이트에서 동작이 달라질 수 있습니다.
